# 测试流程（8 步）

这份文档是 [test-console-ux](https://github.com/obra/superpowers) 模式在本项目的落地：
每个步骤都有前置条件、可观察结果、失败模式、安全状态、暂停点和进度单位。

## 1. Task & State Table

| # | 步骤 | 前置条件 | 动作 | 可观察结果 | 失败模式 | 安全状态 | 可暂停点 | 进度 |
|---|---|---|---|---|---|---|---|---|
| 1 | 连接/自检 | 三个串口存在 | 查 `*IDN?`、`STATUS`、补偿状态 | 型号/固件/端口 | 未连接、型号不符 | 关端口 | 否 | 1 步 |

## 2. 状态机

```
idle -> preflight -> running -> done
                       |  ^
                     pause |
                       v  |
                     paused
                       |
                    stopping -> idle
                       |
                     error
```

实现文件：`core/tasks.py` 的 `TestState` / `TaskProgress`。

- `RUNNING` 时只允许暂停/停止；
- `PAUSED` 时保持偏置和继电器，恢复后从安全点继续；
- `STOPPING` 不立刻杀线程，等当前采样/阶段结束再断电；
- `ERROR` 记录失败步骤，输出回安全态，按钮恢复可用；
- 关闭窗口 = 停止 + 断电 + 继电器开路。

## 3. 界面合同

- 当前步骤：`3/8 · 短路校准`；
- 总进度条 0–8；
- 步内进度：`3/8 · 测量 CISS · 采样 7/10`；
- 按钮：运行全部 / 执行选中 / 暂停 / 停止；
- 结果表：参数、主值、副值（D/θ）、单位、n、极差%；
- 日志：时间戳、步骤、错误；
- 预检失败时不能开始测量。

## 4. 使用

1. 连接 TH2840E / STM32 / TH1992；
2. 选“运行全部”，或在下拉框选某一步后点“执行选中”；
3. 测量中可“暂停/继续”，偏置和继电器保持；
4. “停止”在当前安全点后断电、继电器开路；
5. 结果同时写界面表、SQLite（`data/measurements.db`）和 CSV。

## 5. 验收

- 进度条能显示 `3/8` 和 `采样 7/10`；
- 暂停 30 s 后继续，结果与不暂停一致；
- 运行中拔设备，UI 进入 error 并断电；
- 关闭窗口后 CH1/CH2 回 0 V、继电器开路；
- 同一 run 能在数据库/CSV 中还原每一步条件和原始点。
