> 原 `技术文档_CICC1006571.docx` 含本机用户目录截图与个人文档属性，仅保留在 **private 仓库/比赛材料**，不进入公开包。

## 1. 目标

基于 TH1992 双通道源表、TH2840E 精密 LCR 电桥和 STM32 十路继电器矩阵，测量 TK9J90E 等 MOSFET 的 Ciss / Coss / Crss / Rg。

## 2. 测量原理

- **Ciss**：S 与 D 交流短接，从 G 看进去，Cgs 与 Cgd 并联；
- **Coss**：G 与 S 交流短接，从 D 看进去，Cds 与 Cgd 并联；
- **Crss**：S 悬空，LCR 从 G 注入、D 返回，主要测 Cgd；
- **Rg**：栅极分布电阻与 Ciss 串联，高频下用阻抗实部近似，需短路扣除或四线改造。

## 3. 继电器矩阵

- 9 路基表 K1–K9，10 路板新增 K10：RG(开)/RG(短) 闭合，其余断开；
- 关键复核：**COSS 的 K6 必须闭合**；
- 时序：先切继电器，再开电源；先关电源，再切继电器；
- 真值表见 [`../relay_truth_table.md`](../relay_truth_table.md)。

## 4. 偏置与接线

- TH1992 **CH1 = 漏极 DC_H**，0~100 V；Ciss/Coss/Crss 用 25 V，Rg 用 0 V；
- TH1992 **CH2 = PCB / 继电器板 +5 V**；
- 栅极由 **LCR 内部 DC bias** 提供，当前 Vg=0 V；
- LCR 的 Hp/Hc/Lp/Lc 合并为 `LCR_H` / `LCR_L` 两线；
- 接线见 [`../hardware/wiring.md`](../hardware/wiring.md)。

## 5. 测量条件与结果

- LCR：1 MHz，AC 50 mV；
- 历史表 5.1 是 **5 次独立测量**；当前软件单次测量内部采样 **10 点**，再取中位数/均值/标准差/极差，两者不是同一统计口径；
- 数据表与复现方式见 [`../measurement_report.md`](../measurement_report.md)。

## 6. 软件与固件

- 上位机：PyQt5，SCPI 控制 TH2840E/TH1992，8 步任务流程；
- 固件：STM32F103C8，USART 115200，控制 K1–K10；
- 结果写 SQLite/CSV，包含条件、统计量、原始点与副参数 D/θ；
- 设计说明见 [`../../PORTFOLIO.md`](../../PORTFOLIO.md)。
